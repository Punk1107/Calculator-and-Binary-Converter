# Modular Calculator & Binary Conversion System

A Python application that provides mathematical calculations and number system conversion tools.  
The project focuses on clean and modular software design to improve maintainability and future scalability.

## Features

- Basic calculator operations
- Binary ↔ Decimal conversion
- Reservation management module
- Command-line interface (CLI)

## Technologies

- Python
- Git & GitHub

## Project Structure

Calculator-and-Binary-Converter/
│
├── Main.py
├── Reservation.py


The project is currently being refactored to introduce a more modular architecture and support future feature expansion.

## How to Run

Clone the repository

git clone https://github.com/Punk1107/Calculator-and-Binary-Converter.git


Run the application

python Main.py
